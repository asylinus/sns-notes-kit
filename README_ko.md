# 내 인스타·스레드 글을 노트로 만들기 (snsnotes)

내가 쓴 인스타그램 / 스레드 글을 **내 컴퓨터 안에서만** 정리해 줍니다.

- 글 하나당 메모 파일 하나 (날짜·원문 포함)
- 노트북LM에 바로 올릴 수 있는 연도별 묶음 파일
- 올리기 전에 개인정보가 있는지 알려주는 점검 보고서 (내용은 보여주지 않고, 개수와 글 날짜만 알려줍니다)

인터넷으로 아무것도 보내지 않습니다. 자세한 내용은 [PRIVACY.md](PRIVACY.md)를 보세요.

---

## 1단계. 파이썬 설치 (처음 한 번만)

1. https://www.python.org/downloads/ 에서 파이썬을 받아 설치합니다 (3.10 이상).
2. **Windows**: 설치 첫 화면 아래의 **"Add python.exe to PATH"** 에 꼭 체크하세요.

![스크린샷 자리: 파이썬 설치 화면](docs/img/00_python.png)

이미 설치되어 있다면 건너뛰세요.

## 2단계. 내 데이터 내려받기 (JSON 형식)

1. 인스타그램 앱 또는 웹에서 왼쪽 아래 **더 보기(More)** > **설정(Settings)** 으로 들어갑니다.
2. **Meta 계정(Meta Account)** 을 누르고, **내 정보 및 권한(Your information and permissions)** 을 누릅니다. (아직 Meta 계정으로 바뀌지 않은 계정은 이 자리에 **계정 센터(Accounts Center)** 가 보일 수 있습니다. 같은 메뉴입니다.)
3. **내 정보 내보내기(Export your information)** > **내보내기 만들기(Create export)** 를 누릅니다.
4. 내 프로필을 고르고 **다음(Next)** > **기기로 내보내기(Export to device)** 를 선택합니다.
5. **정보 유형 일부 선택**에서 **게시물**을 고르고, 스레드를 쓴다면 **Threads**도 고릅니다. 기간은 **전체 기간**.
6. **형식은 반드시 JSON** 으로 고릅니다. (HTML을 고르면 이 도구가 읽지 못합니다.) 알림 받을 이메일을 확인하고 **내보내기 시작(Start export)** 을 누릅니다.
7. 준비되면 메타가 이메일과 알림으로 알려 줍니다. 최대 30일까지 걸릴 수 있습니다. 같은 메뉴의 **다운로드 가능 항목(Available downloads)** 에서 zip 파일을 내려받으세요. **링크는 4일 동안만** 유효합니다. 압축은 풀지 마세요.

(메뉴 이름은 한국어 화면에서 조금 다르게 보일 수 있습니다. 출처: Instagram 고객센터 "Review and export a copy of your Instagram information", https://help.instagram.com/181231772500920, 2026-10-03 확인)

![스크린샷 자리: 다운로드 요청 화면](docs/img/01_request.png)
![스크린샷 자리: 형식을 JSON으로 선택](docs/img/02_json.png)

## 3단계. 실행하기

**Windows**

1. 이 폴더의 `run_windows.bat` 파일을 찾습니다.
2. 내려받은 zip 파일을 `run_windows.bat` 위로 **끌어다 놓습니다**.
3. 검은 창이 뜨고 잠시 후 "완료"가 나옵니다.

**Mac**

1. 처음 한 번, 터미널에서 `chmod +x run_mac.command` 를 실행합니다. ("확인되지 않은 개발자" 경고가 뜨면 파일을 우클릭 > 열기)
2. zip 파일을 `run_mac.command` 위로 끌어다 놓습니다.

![스크린샷 자리: zip을 bat 파일 위로 끌어다 놓기](docs/img/03_drag.png)

## 4단계. 결과 확인

zip 파일 옆에 `<zip이름>_snsnotes` 폴더가 생깁니다.

| 이름 | 내용 |
| --- | --- |
| `scan_report.md` | **먼저 읽으세요.** 전화번호·이메일·계좌번호 비슷한 숫자·다른 사람 @언급이 몇 개, 어느 날짜 글에 있는지 |
| `notes/` | 글 하나당 메모 하나 (옵시디언 같은 노트 앱에 그대로 넣을 수 있음) |
| `nlm/` | 노트북LM용 파일. 연도별로 나뉘고, 너무 길면 자동으로 `_part2` 등으로 쪼개짐 |

## 5단계. 노트북LM에 올리기 전에

1. `scan_report.md`에서 개인정보가 있는 날짜의 글을 확인하세요.
2. 전화번호·이메일·계좌번호를 가리고 싶다면 명령줄에서 `--redact`를 붙여 다시 실행합니다:
   `python -m snsnotes all 내파일.zip --redact`
3. 노트북LM(구글)에 올리면 내용이 구글 서버로 갑니다. 올릴 연도와 파일을 직접 고르세요. 다른 사람 이야기가 많은 글은 빼는 것이 안전합니다.

## 자주 묻는 질문

- **"파이썬이 없다"고 나와요** > 1단계를 하고, Windows는 PATH 체크를 했는지 확인하세요.
- **"JSON 내보내기가 아닌 것 같다"고 나와요** > 2단계에서 형식을 HTML로 골랐을 가능성이 큽니다. JSON으로 다시 요청하세요.
- **시간이 이상해요** > 기본은 내 컴퓨터 시간대입니다. 직접 지정하려면 `--tz KST` (한국 시간).
- **다시 실행해도 되나요?** > 네. 이미 만든 노트는 건너뜁니다.
